# 3D魔方展示与操作程序

一个基于HTML、CSS和JavaScript开发的3D魔方交互程序，支持魔方的展示、旋转和还原功能。

## 功能特性

### 🎨 视觉效果
- 3D魔方展示，具有真实的立体效果
- 六个面分别使用标准魔方颜色：
  - 前面：绿色
  - 后面：红色
  - 上面：白色
  - 下面：黄色
  - 左面：橙色
  - 右面：蓝色
- 平滑的旋转动画效果

### 🎮 交互功能

#### 面旋转
- **前面(F)**：顺时针/逆时针旋转
- **后面(B)**：顺时针/逆时针旋转
- **上面(U)**：顺时针/逆时针旋转
- **下面(D)**：顺时针/逆时针旋转
- **左面(L)**：顺时针/逆时针旋转
- **右面(R)**：顺时针/逆时针旋转

#### 层旋转
- **中层(M)**：顺时针/逆时针旋转
- **赤道层(E)**：顺时针/逆时针旋转
- **S层(S)**：顺时针/逆时针旋转

#### 整体旋转
- **X轴**：顺时针/逆时针旋转
- **Y轴**：顺时针/逆时针旋转
- **Z轴**：顺时针/逆时针旋转

#### 其他功能
- **还原魔方**：一键恢复初始状态

## 技术实现

### HTML结构
- 魔方容器：`.cube-container`
- 魔方元素：`#cube`
- 控制按钮区域：`.controls`
- 27个小方块：`.cubelet`
- 每个小方块的6个面：`.face`

### CSS样式
- 使用CSS 3D变换实现立体效果
- `perspective`和`perspective-origin`创建透视效果
- `transform-style: preserve-3d`保持3D空间关系
- 平滑的过渡动画：`transition: transform 0.4s ease`
- 响应式设计，适配不同屏幕尺寸

### JavaScript逻辑
- `initCube()`：初始化魔方
- `createCubelet(x, y, z)`：创建单个小方块
- `rotateFace(face, direction)`：旋转指定面
- `rotateLayer(layer, direction)`：旋转指定层
- `rotateCube(axis, direction)`：整体旋转魔方
- `resetCube()`：还原魔方

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 使用左侧控制面板的按钮进行操作：
   - 选择要旋转的面、层或整体
   - 点击顺时针或逆时针按钮
   - 点击"还原魔方"恢复初始状态

## 开发说明

本项目使用纯前端技术实现，无需后端服务器。所有逻辑都在浏览器中运行。

### 自定义设置

- 调整`.cubelet`的大小
- 修改颜色方案
- 调整旋转动画速度
